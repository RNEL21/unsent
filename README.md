# Неотправленное

## О проекте

«Неотправленное» - личный архив для текстов, которые хочется написать, но не отправлять: непроговорённый ответ, письмо бывшему человеку или мысль, оставленная среди ночи. Пользователь сдаёт текст в воображаемую телеграфную контору: он сохраняется в личном ящике, а не отправляется адресату.

Идея проекта - превратить обычное сохранение текста в спокойный ритуал и со временем дать автору возможность перечитать собственные записи.

## Что реализовано

- **Приём телеграммы:** необязательное поле адресата, редактор текста, счётчик знаков и автосохранение черновика.
- **Ритуал сдачи:** перед анимацией запись сохраняется в архив. Бланк складывается и уходит в ящик; анимацию можно пропустить с клавиатуры или кликом.
- **Личный архив:** записи сгруппированы по месяцам; доступны поиск по содержимому, адресату и заметкам, а также просмотр полного текста.
- **Ежемесячное возвращение:** в первое воскресенье месяца приложение предлагает одну запись. Выбор фиксируется на месяц; к записи можно дописать заметку.
- **Статистика и экспорт:** сводные показатели по архиву и выгрузка записей в JSON или TXT.
- **Адаптивный интерфейс:** сцены и элементы управления рассчитаны и на мобильный экран; для анимации учитывается настройка `prefers-reduced-motion`.

## Продуктовые и технические решения

- **Local-first:** записи хранятся в браузере пользователя, без аккаунта и собственного сервера.
- **Сохранение прежде анимации:** запись попадает в архив в момент нажатия кнопки. Анимация показывает путь листа и не отвечает за сохранность данных.
- **Архив без удаления:** в приложении нельзя удалить отдельную запись; вместо этого предусмотрен экспорт архива.
- **Честность о хранении:** очистка данных сайта в браузере удалит локальный архив, поэтому экспорт доступен из интерфейса.
- **Единый визуальный язык:** ночная телеграфная контора, бумажные бланки, локально подключённые шрифты и тёплый свет настольной лампы.

## Что демонстрирует проект

Проект показывает полный путь от продуктовой идеи до работающего веб-приложения: определение пользовательских сценариев, проектирование интерфейса и визуальной системы, организацию состояния и маршрутов, локальное сохранение данных, экспорт и обработку доступности анимации.

## Технологии

- React 18 и JavaScript
- Vite
- Zustand с сохранением состояния в `localStorage`
- Framer Motion для анимаций интерфейса
- React Router для экранов приложения
- Self-hosted шрифты Inter, Literata и Playfair Display

## Запуск локально

Требуется установленный Node.js.

```bash
npm ci
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

В режиме разработки доступны демо-данные и проверки ритуала:

- `/?seed` - заполнить архив демонстрационными записями;
- `/?send-demo` - запустить анимацию сдачи;
- `/?storyboard` - посмотреть основные позы анимации на одном экране.

## Деплой

Проект настроен для Vercel. После импорта репозитория используется команда сборки `npm run build` и папка результата `dist`. Файл `vercel.json` содержит правило для прямого открытия маршрутов приложения.
