# Неотправленное

Личный архив текстов, которые вы написали, но никогда не отправите: ответ начальнику,
сообщение бывшей, черновик поста, мысль среди ночи.

Это не мессенджер и не заметки. Это **ночная телеграфная контора на одного посетителя**:
каждый текст — телеграмма, которую приняли, но никогда не передадут. Она складывается,
получает штамп «ПРИНЯТО» и уходит в ящик конторы. Ничего не сгорает — записи хранятся
по датам. Раз в месяц — «возвращение» — контора возвращает одну телеграмму обратно.
Через год это становится историей самого себя: что хотел сказать и не сказал.

## Атмосфера

Комната ночью: глубокий синевато-серый фон (`#14181f`), единственный источник тепла —
лампа (`#e8b04b`), пятно которой знает час: глубокой ночью оно уже и теплее, днём —
шире и слабее. Работа идёт на светлом бланке (`#efe6d3`) с печатной сеткой граф,
линованными строками и чернилами (`#2b2416`). Второй акцент один — штамп (`#9b3b2e`).
Типографика: Playfair Display для литер-заголовков, Literata для текста телеграмм,
Inter для граф формуляра и интерфейса. Все шрифты self-hosted (latin + cyrillic).

## Экраны

- **Приём** — бланк телеграммы под лампой: графы «Кому» и «Текст», счётчик знаков,
  кнопка «Сдать в ящик». Черновик автосохраняется; рядом с кнопкой честное
  «Никуда не отправится. Останется в ящике.» Ctrl+Enter — тоже сдача.
- **Ритуал сдачи** — кульминация: бланк складывается вдвое, штамп «ПРИНЯТО» бьёт
  по листу, стек падает в светящуюся щель ящика (~2 секунды, framer-motion;
  клик/Enter/Escape пропускает, prefers-reduced-motion получает тихое затухание).
  Запись коммитится в момент клика — анимация изображает путь листа, а не сохраняет его.
- **Ящик** — сортировочный шкаф: поданные бланки с датами-штампами, картонные
  разделители месяцев со счётчиками, поиск по тексту, адресатам и заметкам.
  Клик разворачивает формуляр.
- **Возвращение** — в первое воскресенье месяца контора возвращает одну телеграмму
  (выбор фиксируется на месяц). «Обратно в ящик», «Дописать мысль» (продолжение
  сохраняется в записи) или «В другой раз» — ритуал зовёт, но не держит.
- **Учёт** — книга приёма: сколько телеграмм принято (и ни одна не передана),
  тепло-лента 12 месяцев со значениями, самый многословный и самый тихий месяц,
  выгрузка архива в JSON/TXT.

## Технологии

- React 18 + Vite, JavaScript (без TypeScript)
- framer-motion — ритуал сдачи, раскрытие бланков, переходы через глубину
- Zustand (persist) — состояние, черновик и архив в localStorage
- react-router-dom — маршруты `/`, `/drawer`, `/sunday`, `/stats`
- Шрифты self-hosted: `public/fonts/` (27 woff2, latin + cyrillic)
- Деплой на Vercel (`vercel.json` с SPA-rewrite уже в репозитории)

Модель записи:

```js
{ id, to: string | null, text, createdAt, monthKey, note: string | null }
```

Удаления нет — это принцип концепта («ничего не сгорает»). Взамен — экспорт архива
на экране «Учёт»: обещание «никуда не денется» должно быть правдой, а не надеждой.

Структура:

```
src/
  pages/       Desk (Приём), Drawer (Ящик), Sunday (Возвращение), Stats (Учёт)
  components/  SendAnimation (ритуал), FiledForm (поданная телеграмма), NavBar
  hooks/       useArchive (CRUD + черновик), useSunday (ежемесячный ритуал)
  utils/       date.js (месяцы, лампа со временем), export.js, session.js
  store.js     Zustand + persist (localStorage, ключ "unsent-archive")
DESIGN.md      визуальная система мира (токены, роли, компоненты)
PRODUCT.md     продуктовая правда
```

Дизайн и редизайн велись со скиллом [impeccable](https://github.com/pbakaus/impeccable):
критика (19/36) → выбор визуального мира через concept-seed → редизайн →
finish-review (две материальные находки исправлены, вердикт ship) → DESIGN.md.
Критерии качества и история решений — в `.impeccable/`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Демо-данные для разработки: `http://localhost:5173/?seed` (только dev-режим).

Сборка и предпросмотр:

```bash
npm run build
npm run preview
```

## Деплой на Vercel

1. Запушьте репозиторий на GitHub/GitLab.
2. На vercel.com: **Add New → Project**, выберите репозиторий.
3. Vercel сам определит Vite (build: `npm run build`, output: `dist`).
4. Deploy. `vercel.json` уже содержит rewrite всех путей на `index.html`,
   так что прямые ссылки вида `/drawer` работают.

Или из терминала: `npx vercel`.

## Как работает «возвращение»

«Возвращение» — первое воскресенье каждого месяца. В этот день приём один раз
за сессию предлагает ритуал, а в навигации у пункта «Возвращение» горит тёплая точка.
Возвращаемая телеграмма фиксируется на месяц и не меняется от новых записей.
«В другой раз» отпускает до следующего месяца. Экран доступен в любой день через
навигацию — ящик никогда не заперт.

Все данные живут только в вашем браузере (localStorage). Очистка данных сайта
удалит архив безвозвратно — поэтому в «Учёте» есть выгрузка.
